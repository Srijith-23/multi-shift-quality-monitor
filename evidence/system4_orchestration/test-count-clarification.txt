implementation and cover distinct requirements, including tiered state,

fork isolation, and scratchpad merging.

The reviewer rubric currently expects 28 tests, but the supplied project
instructions and reference solution specify 33. Therefore the evidence
reports the actual complete suite result of 33 passed rather than deleting
five valid tests solely to match the conflicting count.
